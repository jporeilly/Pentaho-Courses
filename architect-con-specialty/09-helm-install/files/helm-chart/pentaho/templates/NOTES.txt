================================================================================
 Database Management
================================================================================

To connect to PostgreSQL:

  kubectl exec -it deployment/postgres -n {{ include "pentaho.namespace" . }} -- psql -U postgres

To list all databases:

  kubectl exec -it deployment/postgres -n {{ include "pentaho.namespace" . }} -- psql -U postgres -c "\l"

To backup PostgreSQL:

  kubectl exec deployment/postgres -n {{ include "pentaho.namespace" . }} -- \
    pg_dumpall -U postgres > pentaho-backup-$(date +%Y%m%d).sql

================================================================================
 Troubleshooting
================================================================================

If Pentaho pod is not starting:

1. Check pod events:
   kubectl describe pod -l app=pentaho-server -n {{ include "pentaho.namespace" . }}

2. Check PostgreSQL is ready:
   kubectl get pods -l app=postgres -n {{ include "pentaho.namespace" . }}

3. View init container logs:
   kubectl logs -l app=pentaho-server -n {{ include "pentaho.namespace" . }} -c wait-for-postgres

If you encounter "Cannot obtain JCR repository" error:
- Ensure PostgreSQL is running and initialized
- Check database connection settings in ConfigMap

For more help, visit:
  https://github.com/yourusername/Pentaho-K3s-PostgreSQL
