# Course diagrams

`pentaho-architecture.svg` (User Console, "Pentaho Architecture") is hand-laid,
not Mermaid, so every box lines up and each arrow is labelled with the file
that travels along it. Edit `pentaho-architecture.svg.mjs`, run it with `node`,
and render the SVG at 2x (any headless browser screenshot at 2020x1048, the
image shown at width 2020) to `../images/getting_started_pentaho_architecture.png`.
