# Overview of Community Data Access

<div class="pcm-intro">

**Community Data Access (CDA)** is the data abstraction layer for CTools dashboards. It sits between your dashboards and the underlying data, letting you combine sources, run parameter-driven queries, apply security, preview results, and export to standard formats — all through a single, consistent interface.

</div>

> **Note:**
>
> #### Understanding CDA for dashboard data integration
>
> Community Data Access (CDA) is a powerful Pentaho plugin that simplifies dashboard data management. While Pentaho offers multiple data access methods — including XMLA and Kettle transformations exposed as web services — CDA stands out for its ease of use and flexibility.

## Key features and capabilities

> **Note:**
>
> #### What CDA gives you
>
> - Direct access to various data sources
> - Parameter-driven queries for targeted results
> - Built-in data preview functionality
> - Data manipulation and transformation tools
> - Export options to standard formats
> - Ability to combine multiple data sources through joins and unions

## Implementation approaches

> **Note:**
>
> #### Code-free or programmatic
>
> CDA accommodates both code-free and programmatic implementations. While you can create data sources without writing code, understanding the underlying XML structure and coding principles provides deeper insight into CDA's functionality.

The beauty of CDA lies in its simplicity — whether you prefer visual tools or hands-on coding, you can effectively:

- Configure data sources
- Design custom queries
- Transform data outputs
- Create dashboard-ready datasets

This streamlined approach eliminates the need for complex data parsing, making dashboard development more efficient and accessible.
